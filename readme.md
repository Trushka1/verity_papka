# Ресторан

Лабораторная работа №1. Консольная программа для управления меню ресторана и заказами. Блюда и заказы сохраняются в JSON-файлах, поэтому данные остаются после закрытия программы.

## Требования

Python 3.6 или новее. Дополнительные библиотеки устанавливать не нужно.

## Запуск программы

Открой терминал в папке проекта и выполни:

```powershell
py main.py
```

На Windows также можно запустить командой `python main.py`.

При первом запуске программа создаст папку `data` и файлы `dishes.json` и `orders.json`, если их ещё нет. После добавления, изменения или удаления данных соответствующий JSON-файл обновляется.

## Запуск тестов

Из корневой папки проекта выполни:

```powershell
py -m unittest discover -s tests -v
```

Тесты проверяют правила работы заказов, сохранение цены блюда в заказе и восстановление данных из JSON после повторного создания хранилища.

## Структура проекта

| Файл или папка | Назначение |
| --- | --- |
| `data_layer.py` | Классы блюда, позиции заказа и заказа. |
| `repository_layer.py` | Общий интерфейс хранилища и хранилище в памяти. |
| `json_repository.py` | Загрузка и сохранение блюд и заказов в JSON. |
| `service_layer.py` | Правила меню и заказов, проверка данных и расчёт суммы. |
| `main.py` | Консольное меню и запуск программы. |
| `data/dishes.json` | Сохранённые блюда меню. |
| `data/orders.json` | Сохранённые заказы. |
| `tests/test_restaurant.py` | Автоматические тесты программы. |
