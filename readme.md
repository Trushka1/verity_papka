# Ресторан

Лабораторная работа №1.

Консольная программа для ведения меню и заказов ресторана. Данные хранятся в памяти до выхода из программы.

## Запуск

Нужен Python 3.6 или новее. Открой терминал в папке проекта и выполни:

```bash
python3 main.py
```

## Пример работы

1. Пункт 1 — добавь блюдо «Суп» за 250 рублей. Программа покажет ID блюда.
2. Пункт 5 — открой заказ для столика 3. Программа покажет ID заказа.
3. Пункт 6 — введи ID заказа, ID блюда и количество 2.
4. Пункт 7 — посмотри заказ. Сумма составит 500 рублей.
5. Пункт 8 — закрой заказ. Добавлять блюда в него больше нельзя.

Цена блюда запоминается при добавлении в заказ. Если потом поменять цену в меню, сумма уже добавленных позиций не изменится.

## Структура проекта

| Файл | Что в нём |
| --- | --- |
| `data_layer.py` | Классы блюда, заказа и позиции заказа. |
| `repository_layer.py` | CRUD: добавить, получить, обновить и удалить объект. |
| `service_layer.py` | Правила работы меню и заказов, расчёт суммы. |
| `main.py` | Консольное меню, ввод и вывод, запуск приложения. |

В проекте видны два принципа SOLID. **S** — у каждого слоя своя задача. **D** — сервис работает через общий интерфейс `Repository`. Для хранения в файле можно реализовать тот же интерфейс и передать новое хранилище при создании сервиса в `main.py`. Правила заказов остаются в сервисе.
